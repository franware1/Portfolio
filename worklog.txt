CURRENT TECH STACK (as of 2026-10-13)
─────────────────────────────────────────────
Frontend:  React 19 + TypeScript, Vite 7, React Router DOM 7
Styling:   Plain CSS with custom properties (no Tailwind/Bootstrap), split per area
           in src/styles/ and aggregated by styles.css; local Playfair Display +
           Open Sans variable fonts; light/dark theme via [data-theme]
Backend:   Node.js (>=18) + Express 5 (backend/emailer.js). Mail via Resend HTTPS
           API when RESEND_API_KEY is set, else Nodemailer over Gmail SMTP; cors, dotenv
Deploy:    Railway (https://franciscovu.up.railway.app). In production one Express
           process serves dist/ and POST /api/contact
